# Guía de capturas
1. Home completa: menú, hero, tarjetas y footer.
2. Listado: buscador, filtro, tarjetas y contador.
3. Detalle: imagen, título, fecha, contenido y favorito.
4. Contacto: formulario completo.
5. JSON: DevTools > Network > servicios.json, además del listado cargado.
6. Búsqueda/filtro: resultado reducido después de escribir/seleccionar.
7. Favoritos: guardar un elemento y mostrarlo en Favoritos.
8. Persistencia: recargar y demostrar que sigue guardado.
9. Validación: enviar vacío o correo inválido y capturar errores.
10. Validación correcta: formulario completo y mensaje de éxito.
11. Responsive: DevTools en móvil.
12. Estructura: VS Code mostrando HTML/CSS/JS/data/images.
13. GitHub: repositorio con todos los archivos.
Para Entrega 1, usa capturas de las cuatro pantallas como mockups si el docente acepta el prototipo visual; si exige Figma, recrea estas cuatro vistas en Figma y captura allí.
